      How a trial works

      1. Discovery. The prosecution and the defense each search the same documents for passages that support or contradict the claim.
      2. Arguments. Each side argues its position. Every point must cite an exhibit, for example E12.
      3. Evidence check. Citations are verified in code. Points that cite exhibits a side never retrieved are struck.
      4. Ruling. The judge sees only the admitted exhibits and returns a verdict with reasons and a confidence score.
